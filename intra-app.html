Cargar archivo de tickets

El archivo XLSX debe tener la estructura del backlog. Tres formas de cargarlo:

Arrastra el archivo XLSX aquí
o haz clic para seleccionarlo
Google Drive: abre el archivo, comparte como "Cualquiera con el enlace", copia el ID y úsalo así:
https://drive.google.com/uc?export=download&id=TU_FILE_ID

También funciona con Dropbox (cambiar ?dl=0 por ?dl=1) o cualquier URL pública con CORS habilitado.
Si el HTML y el XLSX están en la misma carpeta del proyecto (servidos por un servidor local o subidos juntos), esta ruta relativa funcionará.

Tip: en el directorio del proyecto ejecuta python3 -m http.server 8000 y abre http://localhost:8000.
